# Odin Recipes

Hours deep in focus mode, hands glued to the keyboard until your brain switches to survival mode: feed me. You've got the ingredients. You just need the idea. That's Odin Recipes.

## About

A simple recipe collection built as part of [The Odin Project](https://www.theodinproject.com/)
HTML Foundations course, practicing headings, lists, links, images, and semantic HTML structure.

## What's Inside

- Recipe list with links to individual pages.
- Ingredients and step-by-step instructions for each dish
